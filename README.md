# Bolan Gasoline — Petrol & Diesel Pump ERP (Flutter Mobile + Desktop)

Cross-platform **Mobile + Desktop + Web** Fuel Station ERP built in Flutter for **Bolan Gasoline**.

## Features
- **6 Clean, Bloat-Free Modules:**
  1. Dashboard (4 KPIs, Petrol & Diesel Tank Progress Cards, Recent Sales, Top Credit Balances)
  2. Fuel Sales (Walk-in Cash + Per-Purchaser Dynamic Rate Entry)
  3. Fuel Stock & Purchases (Tanker Arrivals, Supplier Bills, Tank Capacity & Rate Settings)
  4. Purchasers Khata & **Individual Personal Ledger Account History** (e.g., Arsalan's full chronological statement with running balance)
  5. Suppliers Ledger & Individual Supplier Statement History
  6. Expenses & Staff Salaries
- **Full CRUD + Multi-Select Checkbox Bulk Delete:** Add, Edit, Single Delete, and Checkbox Select All / Bulk Delete with automatic stock & balance recalculation.
- **6 Live Themes:** Bolan Red (Crimson), Orange, Emerald, Ocean, Indigo, and Dark Mode.
- **Full Bilingual Support:** English (LTR) and Urdu (RTL) live toggle.
- **Offline-First Local Persistence:** Data persists locally across reloads + Online/Offline Auto-Sync mode.
